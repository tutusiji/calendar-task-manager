- 团队列表支持拖拽排序
- 项目列表支持拖拽排序

## 如何更新 SQL

如果你这次走手动 SQL 路线，建议按下面顺序做。

### 第 1 步：先备份数据库

```bash
docker exec -t calendar-postgres pg_dump -U postgres -d calendar_tasks > calendar_tasks_backup_2026-05-07.sql
```

### 第 2 步：把 SQL 文件拷到服务器

假设部署包路径是 `/opt/calendar-task-manager/update-2026-05-07/`：

```bash
docker cp /opt/calendar-task-manager/update-2026-05-07/database-sync-post-2026-04-15.sql calendar-postgres:/tmp/database-sync-post-2026-04-15.sql
```

### 第 3 步：执行 SQL

```bash
docker exec -it calendar-postgres psql -U postgres -d calendar_tasks -f /tmp/database-sync-post-2026-04-15.sql
```

### 第 4 步：把 Prisma 迁移标记为已应用

如果第 3 步是手工执行 SQL，而不是 `prisma migrate deploy`，建议把 4 条迁移一起标记掉，避免后续升级再次重复执行：

```bash
docker compose run --rm app npx prisma migrate resolve --applied 20260426090000_add_team_project_sort_order
docker compose run --rm app npx prisma migrate resolve --applied 20260426100000_project_member_archive_flags
docker compose run --rm app npx prisma migrate resolve --applied 20260426123000_add_recurring_task_series
docker compose run --rm app npx prisma migrate resolve --applied 20260426153000_add_public_holidays
```

### 第 5 步：触发法定节假日自动写入

法定节假日表只是建表，节假日记录由应用在首次访问接口时自动 upsert。

最简单的做法是：

- 部署完成后，登录系统
- 打开周视图或月视图
- 系统会请求 `/api/public-holidays`
- 随后会自动把内置的 2024-2026 节假日写入 `PublicHoliday`

如果想确认是否已经写入，可以执行：

```sql
SELECT COUNT(*) FROM "PublicHoliday";
```
